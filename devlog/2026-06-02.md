## 技术要点

### CSS 变量切换方案

不使用 CSS 选择器（如 `[data-theme="sunny"]`），而是通过 JS 直接设置 CSS 自定义属性：

```ts
// 切换到 Sunny 主题
document.documentElement.style.setProperty("--theme-midnight", "#fef9ef");
// ...

// 切换回 Midnight（移除变量，fallback 自动生效）
document.documentElement.style.removeProperty("--theme-midnight");
// ...
```

优点：不需要 `!important` 或选择器优先级竞争；fallback 值定义在 `@theme inline` 中，默认主题零开销。
