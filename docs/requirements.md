# 项目需求文档

## 项目概述

**项目名称**：Notion 模板展示网站

**项目目标**：为创作者搭建一个展示和分发 Notion 模板的网页平台，支持付费解锁、会员订阅、双视图浏览。

**目标用户**：面向中国市场，需要模板的 Notion 用户。

---

## 功能需求

### 1. 模板展示

- 支持 **画廊视图**（卡片网格，按标签分组筛选）
- 支持 **列表视图**（按年份分组的时间线样式）
- 两个视图可一键切换，带平滑过渡动画

### 2. 模板信息字段

每个模板包含以下信息：

| 字段 | 说明 |
|------|------|
| 封面图 | 类似 Notion 自带封面上传 |
| 标题 | 模板名称 |
| 描述 | 模板详细说明 |
| 标签 | 多个标签，用于画廊视图分组筛选 |
| 链接 | 1-3 个外部链接（如预览链接、Notion 原版链接） |
| 价格 | 0 = 免费，>0 = 付费 |
| 限免标签 | 标记限时免费 |
| 状态 | draft（草稿）/ published（已发布），只有已发布才对外展示 |
| 发布时间 | 模板发布日期 |
| 创建时间 | 模板创建日期 |

### 3. 付费体系

- **免费模板**：直接跳转到 Notion 模板链接
- **付费模板**：需购买后解锁，支持单次购买
- **会员订阅**：月付/年付会员在有效期内可解锁所有模板
- **支付方式**：微信支付 / 支付宝（前期先做模拟流程）

### 4. 用户系统

- 邮箱注册登录
- 微信扫码登录（预留接口）
- 用户中心（查看订单、会员状态）

### 5. 管理后台

- 可视化增删改查模板
- 封面上传
- 状态切换（草稿 / 已发布）
- 模板数据支持从 Notion 数据库同步

---

## 非功能需求

- 高级感 UI 设计，带流畅动效
- 响应式适配（手机/平板/桌面）
- 部署到 Vercel（免费）
- 数据存储用 Supabase（免费额度）

---

## 模板数量

约 50 个模板
