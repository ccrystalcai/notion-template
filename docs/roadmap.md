# 开发路线图

## 总体原则

- **小步快跑**：每个阶段产出可验证的成果
- **安全第一**：环境变量不外泄，用户数据安全
- **稳步推进**：每个阶段验证通过后进入下一阶段

---

## 第 1 阶段：项目初始化 & 基础框架 ✅ 进行中

**目标**：项目能跑起来，有基本页面骨架和视觉主题

- [ ] 初始化 Next.js 项目（App Router + TypeScript + Tailwind）
- [ ] 安装依赖（framer-motion, supabase）
- [ ] 配置 Midnight Galaxy 主题色彩系统
- [ ] 配置全局样式、字体
- [ ] 搭建基础布局（Header + Footer）
- [ ] 创建首页框架（Hero + 视图切换占位）
- [ ] 配置 Supabase 客户端
- [ ] 本地运行验证
